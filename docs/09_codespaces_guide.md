# Codespaces利用手順

この手順では、GitHub Codespacesを起動し、ハンズオンで使うソースや資料を開いて、事前テストを実行します。

## 起動前に確認すること

- GitHubアカウントでサインインできること
- 講師から案内されたリポジトリにアクセスできること
- 組織でCodespacesの利用が許可されていること

Codespacesの利用可否や利用時間には、個人アカウント・組織の設定が適用されます。起動できない場合は講師または組織の管理者に確認してください。

## Codespaceを起動する

1. ブラウザーで[本ハンズオンのGitHubリポジトリ](https://github.com/igarashi0521/csv_import)を開きます。講師から別の配布用リポジトリを指定された場合は、そちらを開いてください。
2. ハンズオンで指定されたブランチを選択します。指定がなければ既定ブランチを使います。
3. リポジトリ画面の **Code** を選び、**Codespaces** タブを開きます。
4. **Create codespace on `<branch>`** を選択します。すでに対象ブランチのCodespaceがある場合は、それを再開してもかまいません。
5. 初回は環境の準備に数分かかることがあります。ブラウザー上にVS Codeの画面が表示されるまで待ちます。

Codespacesタブが表示されない、または作成できない場合は、リポジトリへのアクセス権と組織のCodespaces設定を確認してください。

## ソースと資料を開く

VS Code画面左端の **Explorer**（ファイルのアイコン）を選び、ツリーからファイルを開きます。

- 取込バッチ本体: `src/main/java/com/example/csvimport/Batch.java`
- ハンズオン資料: `docs/` 以下の各Markdownファイル
- README: リポジトリ直下の `README.md`

ファイル名が見えない場合は、Explorer上部のフォルダーを展開します。エディターでファイルを開く操作と、ターミナルでプログラムを実行する操作は別です。

## ターミナルで事前確認する

画面上部の **Terminal** メニューから **New Terminal** を選びます。ターミナルがリポジトリ直下で開いたことを確認し、次を順に実行します。

```sh
java -version
mvn -v
mvn test
```

JDK 17以降、Maven 3.9以降が必要です。初回のMaven実行では依存ライブラリを取得するため、ネットワーク接続が必要で、完了まで時間がかかる場合があります。必要なバージョンが使えない場合や依存ライブラリを取得できない場合は、講師に確認してください。

`mvn test` が成功したら、ハンズオン資料に沿って対象ファイルを編集し、ターミナルでテストやコマンドを実行します。ターミナルに入力したコマンドの結果はターミナルに表示されます。現在のバッチは、正常終了時に取込件数のサマリを画面表示しません（詳しくは[現行設計](08_current_design.md)を参照）。

## 終了する

作業を終えたらファイルの保存を確認し、GitHubのCodespaces一覧から対象Codespaceのメニューを開いて **Stop codespace** を選びます。ブラウザーのタブを閉じるだけではCodespaceが停止しない場合があります。
