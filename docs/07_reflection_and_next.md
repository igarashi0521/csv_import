# 振り返り・ディスカッション・研修後の導線

## ディスカッション(30分)

グループ(3〜4人)で話し合い、各グループ2分で共有します。

1. **AIに任せてよかったこと/人が判断すべきだったこと**は何か(判断記録を持ち寄る)
2. **AIの出力で、間違い・怪しいと感じた点**は何か。どう気づいたか
3. 自分の業務で、**最初に試せそうな小さな場面**は何か
4. 自分の業務でAIを使うとき、**確認を欠かせないポイント**は何か(機密情報、品質、責任)

## 理解度チェック(自己評価:1〜5)

| 観点 | 評価 |
|---|---|
| AIを使った開発の全体像を説明できる | |
| AIに任せる範囲と、人が判断・確認する範囲を区別できる | |
| 「指示・比較・検証」のサイクルを実践できた | |
| 自分の業務での活用イメージを持てた | |

## 研修後の導線

```
業務で小さく実践  →  Academyで継続学習  →  希望者はWGへ参加
```

| ステップ | 内容 |
|---|---|
| 業務で小さく実践 | 今日試したいと書いた場面で、まず1回やってみる(依頼文・差分レビュー・テスト観点出しなど) |
| Academyで継続学習 | 基礎講座(Claude / OpenAI Academy)で、発展内容を学ぶ |
| 希望者はWGへ参加 | 活用ノウハウを共有するワーキンググループに参加する |

> 4時間ですべてを習得するのは難しいため、基礎体験+今後の学習導線を明確にする設計です。

## 事前・事後学習の例

| 時期 | 内容 |
|---|---|
| 事前(任意) | Claude / OpenAI Academy の基礎講座 |
| 事後 | 開発での実践、発展学習、WG参加 |
