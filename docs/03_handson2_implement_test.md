# ハンズオン②:実装・テスト(60分)

**ねらい**:AIに実装とテスト作成を任せつつ、**指示の出し方と検証の仕方**を体験する。

## 進め方

| 時間 | 内容 |
|---|---|
| 1:40-1:50 | 現行ソースとテストの確認、実行(AIなし) |
| 1:50-2:20 | R1・R2・R3 を、小さく分けてAIに実装させる |
| 2:20-2:35 | テストをAIに追加させ、**テストの中身を人が読んで評価する** |
| 2:35-2:40 | 判断記録を書く |

## 事前確認(全員)

```sh
java tools/GenerateSamples.java
mvn test
```

現行テストが全件成功することを確認してから始めます。

## 進め方のコツ

1. **一度に全部頼まない**。R1 → R2 → R3 の順に、1つずつ依頼して動作確認する
2. 依頼するときは「目的」「対象ファイル」「守る制約」「完了条件」を伝える
3. AIが変更したファイルと差分を**必ず自分の目で確認**する(次の時間のレビューにつながる)
4. テストが通っても、**テストが十分かどうか**は別の問題として確認する

## テストの評価観点(AIが書いたテストを読むとき)

- [ ] 実装の中身をなぞっているだけのテストになっていないか
- [ ] 境界値(上限ちょうど・0件・1件)を確認しているか
- [ ] 異常系(エラー行・重複・文字コード違い)を確認しているか
- [ ] 失敗したときに原因が分かるテスト名・メッセージか
- [ ] 一時ファイル・DBを使い、他のテストに影響しないか
